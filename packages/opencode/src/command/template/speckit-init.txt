Initialize a spec-driven development workspace under `.opencode/speckit/`.

Input: $ARGUMENTS

## Requirements
- Determine `featureName` from the input. Treat `--branch` as a flag (remove it from the name).
- Compute `featureId` as a slug for directory names:
  - lowercase, hyphens for spaces
  - keep leading numeric prefix if user provided one (e.g. `001-...`)
  - remove characters that are not letters, numbers, or hyphens
- Create directories:
  - `.opencode/speckit/`
  - `.opencode/speckit/specs/<featureId>/`
- Create/update `.opencode/speckit/context.json` with:
  - `featureId`, `featureName`, `createdAt` (ms timestamp)
  - if `--branch` flag is present: create and switch to git branch `<featureId>` and store `"branch": "<featureId>"`
- Ensure `.opencode/speckit/constitution.md` exists; if missing, create a starter constitution with project principles.

## Rules
- Only write/edit files under `.opencode/speckit/**`.
- Only run bash for safe local operations (mkdir, git branch when requested).
